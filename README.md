# NEURO GOMOKU

ネオン（シアン／マゼンタ）を基調としたサイバーパンク風の五目並べ。
**ビルド不要・APIキー不要・依存パッケージゼロ**で、`index.html` をブラウザで開くだけで動作します。

## 遊ぶ

```bash
git clone https://github.com/Kirei-commits/Gomoku-narabe.git
cd Gomoku-narabe
open index.html            # macOS（Linux: xdg-open / Windows: start）
```

ローカルサーバー経由で開く場合:

```bash
npx http-server . -p 8080  # → http://localhost:8080/
```

GitHub Pages を有効にすれば（Settings → Pages → Source: `Deploy from a branch` / `main` / `/ (root)`）、
そのまま公開URLで遊べます。

## 機能

| 機能 | 内容 |
| --- | --- |
| 対戦モード | 1人用（AI対戦）／2人プレイをワンタッチで切替 |
| AI難易度 | EASY / NORMAL / HARD の3段階。先手・後手も選択可 |
| タップ確認 | 指での操作向け。1回目のタップで位置決め（十字線＋半透明の石）、同じ場所をもう一度タップで着手。指をずらして微調整でき、誤打を防げる |
| 巻き戻し | 棋譜を1手ずつ前後に移動。巻き戻した局面から打ち直すとそこから対局を再開（＝待った） |
| ヒント | 次の一手の推奨と、その理由（受け／攻め／三を止める等）を表示 |
| 詰み筋 | 四追い（VCF）で詰む手順を探索し、盤上に番号付きで手順を表示。1手ずつ辿れる |
| 演出 | 着手時の衝撃波・パーティクル、直前手のマーカー、勝利ラインのレーザー描画 |
| 効果音 | Web Audio API による合成音（音源ファイル不要）。ミュート切替あり |
| 戦績 | 勝敗・引分・連勝・最高連勝を localStorage に保存（難易度別／対人別） |
| レスポンシブ | スマホ縦持ちからデスクトップまで1カラム／2カラムで自動切替 |
| 配慮 | `prefers-reduced-motion` に対応し、演出を抑制。ボタンは最低44pxのタップ領域 |

### キーボードショートカット

| キー | 動作 | キー | 動作 |
| --- | --- | --- | --- |
| 矢印 + Enter | カーソル移動・着手 | `H` | ヒント |
| `R` | 新規対局 | `T` | 詰み筋 |
| `U` | 1手戻る | `C` | タップ確認 切替 |
| `I` | 1手進む | `M` | ミュート切替 |

## ルール

15×15 の盤で、縦・横・斜めのいずれかに先に5個並べたほうが勝ち。
6個以上並んだ場合（長連）も勝ちとする自由五目（フリースタイル）です。禁じ手はありません。

## ファイル構成

```
.
├── index.html        # マークアップ
├── css/style.css     # テーマ・レイアウト・アニメーション
└── js/
    ├── board.js      # 盤面と勝敗判定（純粋ロジック）
    ├── storage.js    # localStorage 永続化
    ├── audio.js      # 効果音の合成
    ├── ai.js         # AI（脅威評価 + αβ探索）
    ├── render.js     # Canvas 描画とエフェクト
    └── main.js       # ゲーム進行とUIバインド
```

依存関係は一方向（`board` → `ai` / `render` → `main`）で、ビルドツールを挟まずに
`<script>` の読み込み順だけで解決しています。各ファイルは即時関数で `window.CG`
名前空間に公開するため、ESモジュールを使わず `file://` でもそのまま動きます。

## AIの仕組み

`js/ai.js` は上位で決まった時点で確定する階層構造で着手を選びます。

1. 自分が即勝ちできる手（五を作る）
2. 相手の即勝ちを止める手
3. 自分の決定的な脅威（活四・四三など）を作る手 ※NORMAL以上
4. 相手の決定的な脅威を潰す手 ※NORMAL以上
5. 四追い（VCF）で詰む手順があればその第一手 ※HARDのみ
6. αβ枝刈り付きネガマックス探索（HARD: 深さ4／NORMAL: 深さ2／EASY: グリーディ + ゆらぎ）

### 詰み筋（VCF）探索

「四を作り続けて相手の応手を強制し、最後に五を作る」手順を探します。四を打たれた側の受けは
五を止める点に限定されるため、探索木は非常に細く、6手先まで読んでも数百ミリ秒で完了します。
受け所が2つ以上になった時点で「受け無し」＝詰みと判定します。相手が先に五を作れる筋は
失敗として枝刈りします。

盤面評価は「5マス窓に自分の石だけが並んでいるか」を全方向で数える静的評価、
着手候補の評価は9マスの並びをパターン表（活四・四・活三…）と照合する方式です。
探索は既存の石から1〜2マス以内の空点に絞り、時間予算（最大900ms）で打ち切ります。

自動対戦（開幕をランダム化して各14局）での強さの目安:
**HARD 9勝3敗2分 vs NORMAL** / **NORMAL 11勝2敗1分 vs EASY** / **HARD 9勝0敗1分 vs EASY**。
1手あたりの思考時間は HARD でも最大 188ms 実測です。

## 検証

Chromium（Playwright）とロジック単体テストで以下を確認しています。

- 勝敗判定（縦・横・斜め・長連・相手石による分断）
- AIの必須着手（即勝ち／四の防御／活三の防御）と応答速度、自動対戦の整合性
- 詰み筋探索の正当性: 自動対戦中に検出した118件の手順すべてを再生し、
  「相手の受けが強制手であること」「最終手で五が成立すること」を検証
- 対局進行・戦績の永続化・巻き戻し／早送り・キーボード操作・非同期処理の競合
- タッチ操作（タップ確認、交点からずれたタップ、盤の角への着手）、
  スマホでのレイアウト（操作バーがファーストビュー内／44px以上のタップ領域／横スクロール無し）
